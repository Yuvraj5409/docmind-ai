# DocMind AI

DocMind AI is a Retrieval-Augmented Generation (RAG) based document intelligence platform that allows users to upload PDFs and notes, process and index their contents, and ask questions about their uploaded documents using natural language. The system extracts text from documents, divides the content into smaller chunks, converts those chunks into vector embeddings, stores them using PostgreSQL with pgvector, and retrieves the most relevant passages when a user asks a question. The retrieved context is then provided to Anthropic Claude to generate a grounded answer, with citations pointing back to the relevant source document and page or chunk. The project is designed as a complete full-stack RAG application using Next.js, TypeScript, Supabase, OpenAI embeddings, Claude, and Vercel rather than simply wrapping a general-purpose chatbot API.
